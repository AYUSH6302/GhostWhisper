WHY OPEN INNOVATION?

A ghost should not need a cloud to haunt you.

With a downloaded open-weight model, stories can be generated locally without sending prompts to a third-party AI service. The interface is built with open web technologies, and the memory vault uses local browser storage. You can change models, inspect the code, and adapt the experience without depending on one AI provider.
